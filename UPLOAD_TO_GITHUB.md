# Upload this project to GitHub (website method)

1. Sign in at https://github.com/CHARITHMAMATHUGAMA .
2. Open https://github.com/new . Repository name: `Python-Network-Port-Scanner`.
3. Set **Public** (if comfortable sharing this code). Do **not** add an auto-generated README, .gitignore or license since this folder already contains them. Select **Create repository**.
4. Select **uploading an existing file** on the empty repository's page.
5. Extract the downloaded project ZIP first, then drag and drop **the files and folders INSIDE** `Python-Network-Port-Scanner` to GitHub's upload page. Include hidden `.github` and `.gitignore` if your file browser shows them; they are optional to the core project but recommended.
6. Enter a commit message such as `Initial commit: Python TCP port scanner` and select **Commit changes**.
7. Refresh the repository, check `README.md` appears on the front page, and copy its URL into your CV.

**Do not upload:** passwords, tokens, secrets, personal system scan results or reports containing sensitive IP addresses. The `reports/` directory is ignored except for `.gitkeep`.
